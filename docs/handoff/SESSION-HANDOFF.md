## 10. The two Claude Code master prompts — what they're for and how they differ
Both live in `E-club-website/docs/claude-code/` and both assume `AGENTS.md` is already loaded (Claude Code reads it automatically from the repo root).

Build order: shell → Home → Events → Team → Sponsors → Gallery → Contact/Join → legal → sitewide SEO pass.
- **`CLAUDE-CODE-AUTOMODE-OVERNIGHT.md`** — for an unattended run. Same persona and same verification rigor (explicitly: verify *more*, not less, because no one will catch a mistake before morning), but adds: work on one single `claude/overnight-<date>` branch all night, never push to `main`, never open a PR (leave that for Wahid to review by hand), never touch CI/security/env files, never invent a fact to unblock, time-box each page so a hard problem doesn't consume the whole night, keep a running timestamped `docs/handoff/BUILD-LOG-<date>.md` instead of conversational reporting, and end with a "MORNING SUMMARY" section listing what's done, what's blocked, every judgment call it made in place of asking, and the exact commands Wahid needs to review it.
