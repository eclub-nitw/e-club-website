# E-Club NIT Warangal — official website

Next.js 16 (App Router, TypeScript strict) + Tailwind v4. Pages are static or revalidated (`revalidate = 60` on Home and `/venture-vortex`); the only server code is `/api/contact` and the daily purge job. Content lives in `src/data/*` and `content/legal/*`. Live: https://e-club-nitw.vercel.app

## Run
```bash
npm install
npm run dev        # http://localhost:3000
npm run build && npm start
npm run lint
```
Node 20+. Tests: `npx playwright test --project=unit` (date logic), `node scripts/test-api.mjs` (needs a build; contact + cron endpoints, 36 checks), `BASE_URL=... npx playwright test` (Chromium/Firefox/WebKit at 360/768/1440 plus the fake-clock suite; start `npm start` first; for WebKit also run `node scripts/https-proxy.mjs` and use `BASE_URL=https://localhost:3443`).

## Environment variables (names only; values live in Vercel, never in git)
`NEXT_PUBLIC_SITE_URL`, `FIREBASE_PROJECT_ID`, `FIREBASE_CLIENT_EMAIL`, `FIREBASE_PRIVATE_KEY`, `CRON_SECRET`. See `.env.example`, `docs/BACKEND.md`, `docs/KEY-ROTATION.md`.

## Where content lives
| To change | Edit |
|---|---|
| Venture Vortex dates | `src/data/timeline.ts` (every date-driven label follows from it via `src/lib/phase.ts`) |
| Venture Vortex facts | `src/data/event.ts`, `src/data/startups.ts` |
| Events | `src/data/events.ts` (+ `src/data/archive.ts` for past sets) |
| Photos | `src/data/media.ts` (generated by `scripts/build-media.mjs`; every photo needs `consent`) |
| Team | `src/data/team.ts`; sponsors `src/data/sponsors.ts` |
| Club-wide facts | `src/data/site.ts`; wording `src/data/copy.ts` |
| Legal text | `content/legal/*.md` (faculty review required; never edit casually) |

Add an event, member, sponsor or photo: add the data entry, drop the optimised file in `public/images/...`, run `npm run build`, open a PR. Anything not yet known is a `CONFIRM`/`TODO` comment in the data file, never in rendered copy.

## Deploy
`main` deploys to production on Vercel; every other branch gets a Preview URL. Never push to `main`: branch `name/feature`, open a PR, a reviewer merges. Domain change: `docs/DOMAIN-CUTOVER.md`.
